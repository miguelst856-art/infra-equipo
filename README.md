# infra-equipo

Repositorio de infraestructura del equipo (Semana 08 – Git, GitHub y DevOps).

## Descripción
Despliegue de un servidor web Nginx con Docker Compose.

## Requisitos
- Ubuntu/Debian con Docker y Docker Compose instalados
- Git y acceso SSH a GitHub

## Cómo desplegar
    git clone git@github.com:miguelst856-art/infra-equipo.git
    cd infra-equipo
    docker compose up -d
    curl http://localhost:8080
